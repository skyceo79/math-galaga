# 매스 갤러그 — 최종 기획안 (확정)

초등학생용 사칙연산 슈팅 게임. 갤러그처럼 숫자 버그를 맞히고, 맞힌 숫자를 **기억했다가** 4지선다로 정답을 고른다.

- 1차: 웹 브라우저에서 테스트
- 2차: 안드로이드 태블릿에 앱으로 설치 (PWA 홈 화면 추가 → 필요 시 APK)
- 분위기: 귀여운 우주 + 파스텔 색감, 버그는 귀여운 캐릭터

## 1. 기본 진행

- 연산 4개(덧셈·뺄셈·곱셈·나눗셈) × 10단계 = 총 40단계
- 단계마다 **정답 20개를 모으면 레벨업**
- 틀리면 정답을 보여 주고, 그 문제는 3문제 뒤에 "복습 문제"로 다시 나온다
- 각 연산 1단계는 처음부터 열려 있고, 다음 단계는 앞 단계를 클리어해야 열린다

## 2. 숫자 버그 규칙

- 버그를 맞히면 그 숫자가 크게 보였다가 사라진다 → 아이가 기억해야 함
  - 보이는 시간: 1단계 1.6초 → 10단계 0.9초
  - 맞힌 숫자를 소리로 읽어 준다
- 화면 위에는 `? + ?` 처럼 기호만 표시
- **회색 철갑 버그**: 단계 규칙에 맞지 않는 버그는 회색이 되고 총알이 튕겨 나간다
  - 뺄셈 음수, 나눗셈 나누어떨어지지 않음, 단계 난이도 불일치를 모두 이 방법으로 막는다
- **나눗셈 변신**: 처음엔 나뉠 수(큰 숫자) 버그만 등장 → 한 마리를 맞히면 나머지가 나누는 수 버그로 변신 (안 맞는 수는 회색)
- **4지선다**: 오답 보기는 아이들이 실제로 자주 하는 실수로 만든다 (±1, 받아올림 빠뜨림, 다른 연산과 혼동, 옆 단 곱 등)

## 3. 미사일과 목숨

- 목숨 3개 (지금 타고 있는 비행기 포함)
- 버그는 적당한 속도로 움직이며 가끔 천천히 날아오는 미사일을 쏜다. 높은 단계일수록 조금씩 늘어남
- 4지선다를 고르는 동안에는 게임이 멈춘다
- 미사일에 맞으면 목숨 -1, 2초 무적(깜빡임). 풀던 문제는 그대로 유지
- 정답을 틀려도 목숨은 줄지 않는다
- **목숨 0개 → "다시 도전!"**: 목숨 3개 다시 채움, 모은 정답 개수 유지, 그 단계 별점 -1
- 게임 오버 없음

## 4. 조작 (태블릿 두 손 잡기)

- 왼쪽 방향키(상하좌우), 오른쪽 발사 버튼
- 비행기는 화면 아래쪽 영역 안에서만 이동
- 화면 위 총알은 최대 2발
- 설정 → "버튼 위치 바꾸기": 드래그로 위치 이동, 크기 조절, **좌우 반전** 버튼(왼손잡이용)
- PC 테스트용: 방향키 + 스페이스바

## 5. 힌트

- 💡 힌트 버튼 → 지금까지 맞힌 숫자를 2초 동안 보여 줌
- 단계마다 5번, 다음 단계에서 다시 채워짐

## 6. 추가 요소

| 요소 | 내용 |
|---|---|
| ⭐ 별점 | 오답 2개 이하 ⭐⭐⭐ / 5개 이하 ⭐⭐ / 그 외 ⭐ — 다시 도전 1번마다 -1 (최소 1개) |
| 👾 보스 버그 | 20번째 문제는 보스. 3번 맞혀야 숫자가 나온다 |
| 🚀 비행기 수집 | 별을 모으면 새 비행기 열림 (6종) |
| 🍎 그림 힌트 | 숫자가 작은 문제에서 틀리면 그림으로 정답 설명 |
| 🔊 소리 | 효과음 + 숫자 읽어 주기 (설정에서 끄기 가능) |
| 👤 프로필 | 아이마다 진도·별·버튼 배치를 따로 저장 |
