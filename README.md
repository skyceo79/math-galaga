# 매스 갤러그

초등학생용 사칙연산 슈팅 게임입니다. 기획 내용은 [docs/기획안.md](docs/기획안.md)에 있습니다.

## 실행 (PC 브라우저)

설치할 패키지가 없습니다. Node.js만 있으면 됩니다.

```bash
node math-galaga/serve.js
```

브라우저에서 http://localhost:5180 을 엽니다.
PC 조작: 방향키로 이동, 스페이스바로 발사, H 키로 힌트.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `js/levels.js` | 연산별 10단계 규칙 (단계표를 바꾸려면 여기) |
| `js/problems.js` | 버그 편대 구성, 회색 철갑 판정, 4지선다 오답 보기 |
| `js/game.js` | 게임 진행 (버그, 총알, 미사일, 목숨, 보스, 복습 문제) |
| `js/art.js` | 버그·비행기·배경 그림 |
| `js/controls.js` | 방향키·발사 버튼, 위치 바꾸기 |
| `js/main.js` | 화면 전환, 프로필, 4지선다·클리어 창 |
| `js/audio.js` | 효과음(합성음), 숫자 읽어 주기 |
| `js/storage.js` | 프로필·별 저장 (기기 안 localStorage) |
| `sw.js`, `manifest.webmanifest` | 태블릿 홈 화면 설치·오프라인 실행 |

## 안드로이드 태블릿에 설치하기 (다음 단계)

- **웹앱(PWA)**: 인터넷 주소(https)에 올리면 태블릿 크롬에서 "홈 화면에 추가"로 설치됩니다. 한 번 열면 그다음부터는 인터넷 없이도 실행됩니다.
- **APK**: 기존 `app/`처럼 Capacitor로 감싸서 설치 파일을 만들 수 있습니다.

`sw.js`의 `VERSION`은 파일을 고친 뒤 배포할 때마다 올려야 태블릿에 새 버전이 반영됩니다.
